# pardus-offline-bundler Kullanım Kılavuzu

Bu araç Pardus 2026 Teknofest Yarışması için geliştirilmiştir.

## Kurulum

Debian paketi olarak kurmak için:
```bash
sudo apt install ./pardus-offline-bundler.deb
```

## Kullanım

Masaüstü başlatıcı ile veya terminalden \$name\ yazarak başlatabilirsiniz.
